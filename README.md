# ➕ Addition Quiz Web App

An interactive web-based quiz that helps users practice addition through randomly generated questions.

## ✨ Features

* Generates addition questions
* Interactive answer input
* Instant result/feedback
* Simple and responsive interface
* JavaScript-based game logic

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
addition-quiz-web-app/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/naveen057/addition-quiz-web-app.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional installation is required.
